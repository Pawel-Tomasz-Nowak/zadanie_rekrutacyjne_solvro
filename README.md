## Struktura projektu

- `src/` — główny kod projektu.
- `requirements.txt` — wymagania biblioteczne projektu.
- `cv_rek/` — lokalne środowisko wirtualne 

## Uruchomienie

Aktywacja środowiska wirtualne:

```powershell
.\\cv_rek\\Scripts\\Activate.ps1
```

Instalacja bibliotek i zależności:

```powershell
python -m pip install -r requirements.txt
```
